## О проекте

**`mml-companion-notes`** — это открытый учебный репозиторий с решениями математических задач и примеров из раздела «Линейная алгебра» книги *Mathematics for Machine Learning* (Marc Peter Deisenroth, A. Aldo Faisal, Cheng Soon Ong), а также с дополнительными примерами, иллюстрирующими связь этих математических идей с практическими задачами машинного обучения.

Все решения реализованы на языке **Python** в формате **Jupyter Notebook** и сопровождаются:

- кратким пересказом условия своими словами,
- математическими пояснениями с формулами в LaTeX,
- пошаговыми вычислениями,
- программным кодом с использованием NumPy, SciPy, SymPy, scikit-learn, PyTorch,
- визуализациями и численными проверками,
- итоговыми выводами и связью с ML.

> ⚠️ **Важно.** Этот репозиторий является **неофициальным сопроводительным материалом** и не связан с авторами книги. Все условия задач пересказаны своими словами; большие фрагменты оригинального текста, иллюстрации и сканы страниц не используются.

---

## Цель проекта

Цель репозитория — помочь студентам и начинающим исследователям:

- **закрепить математические основы**, необходимые для изучения машинного обучения;
- **увидеть прямую связь** между абстрактными математическими понятиями и практическими ML-задачами;
- **получить готовый набор разобранных примеров** с пошаговыми объяснениями и кодом;
- **практиковаться самостоятельно**, опираясь на дополнительные примеры.

Каждый Notebook оформлен в едином формате, что упрощает навигацию и повторное использование материалов.

## Формат Notebook'ов

Каждый Jupyter Notebook следует единой структуре:

```
# Пример NN. Название

## Тема
Раздел книги и математическая тема; связь с ML.

## Условие
Краткий пересказ условия задачи своими словами.

## Математическая идея
Понятия, формулы и методы, используемые в решении.

## Решение
Пошаговое математическое решение с выкладками в LaTeX.

## Реализация на Python
Аккуратно оформленный код с пояснениями.

## Дополнительный пример
Пример, иллюстрирующий связь математической идеи
с практической задачей машинного обучения.

## Проверка результата
Численная проверка, визуализация или альтернативный способ проверки.

## Вывод
Краткий итог и указание, какие математические идеи были продемонстрированы.
```

### Принципы оформления кода

- Код в Notebook выполняется последовательно сверху вниз без ошибок.
- Используются осмысленные имена переменных.
- Графики снабжаются подписями осей, заголовками и легендой.
- Пояснения используют markdown-ячейки с формулами в формате LaTeX.

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/USERNAME/mml-companion-notes.git
cd mml-companion-notes
```

> Замените `USERNAME` на имя пользователя GitHub, на котором будет размещён репозиторий.

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

### 3. Активация виртуального окружения

**Для Windows:**

```powershell
.venv\Scripts\activate
```

**Для macOS и Linux:**

```bash
source .venv/bin/activate
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

---

## Запуск Jupyter Notebook

После установки зависимостей запустите классический Jupyter Notebook:

```bash
jupyter notebook
```

В браузере откроется главная страница Jupyter. Перейдите в каталог `notebooks/` и откройте нужный Notebook.

### Альтернатива: JupyterLab

Если вы предпочитаете современную среду разработки:

```bash
jupyter lab
```
