## Содержание

В главе 2 представлены решения примеров по следующим темам линейной алгебры:

| № | Тема | Связь с ML |
|---|------|------------|
| 01 | Бинарные операции и алгебраические структуры | PCA |
| 02 | Группы вычетов по модулю, эллиптические кривые | Криптография в ML |
| 03 | Группа Гейзенберга, коммутатор | SLAM для автономных роботов |
| 04 | Матричное умножение, некоммутативность | Свёрточные нейросети |
| 05 | Неоднородные системы $Ax=b$, нуль-пространство | Ridge-регрессия |
| 06 | Метод исключения Гаусса | Аналитическое обучение выходного слоя |
| 07 | Собственные значения и собственные векторы | PCA для снижения размерности |
| 08 | Обратные матрицы | Нормализующие потоки |
| 09 | Подпространства $\mathbb{R}^3$ | Визуализация данных, поиск аномалий |
| 10 | Линейная независимость векторов | Проблема «мёртвых нейронов» |
| 11 | Линейная комбинация, разложение по базису | Прямое распространение в нейросети |
| 12 | Пересечение подпространств, ядро блочной матрицы $[V\mid -W]$ | CCA, multi-view learning |
| 13 | Нулевое пространство, ранг и дефект, пересечение ядер $\ker A_1\cap\ker A_2$ | Неразличимость параметров, псевдообратная матрица |
| 14 | Столбцовое пространство (образ), $\dim\mathrm{col}(A)=\mathrm{rank}(A)$, пересечение образов | Проекция МНК, model merging, low-rank |
| 15 | Два метода поиска пересечения подпространств: система уравнений vs ядро блочной матрицы | CCA, выравнивание представлений (representation alignment) |
| 16 | Линейные отображения: аддитивность, однородность, свойства интеграла/производной | Функции активации vs линейные слои |
| 17 | Матрица линейного отображения, ранг, ядро и образ, теорема о ранге и дефекте | Feature collapse, низкоранговые слои, оценка размерности признаков |
| 18 | Ядро и образ композиции при $f\circ g=\mathrm{id}$; левый/правый обратный | Инвертируемые архитектуры (normalizing flows), точное восстановление |
| 19 | Ядро и образ эндоморфизма, смена базиса $\tilde{A}=P^{-1}AP$, инварианты подобия | Диагонализация, PCA, whitening, спектр гессиана |
| 20 | Матрица перехода $P=M_{\text{цель}}^{-1}M_{\text{ист}}$ и матрица гомоморфизма $A'=P_2AP_1$ | Эмбеддинги в разных базисах, whitening, матричная факторизация |
