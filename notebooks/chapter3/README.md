## Содержание

В главе 3 представлены решения примеров по следующим темам аналитической геометрии:

| № | Тема | Связь с ML |
|---|------|------------|
| 01 | Скалярное произведение, проверка аксиом (симметрия, билинейность, положительная определённость) | Метрики расстояний, косинусная близость, проекции в линейных моделях |
| 02 | Проверка скалярного произведения через матрицу Грама; условия симметричности и положительной определённости матрицы $A$ | Взвешенные метрики, Mahalanobis distance, регуляризация через метрику пространства |
| 03 | Вычисление расстояния между векторами через норму, порождённую скалярным произведением; стандартная евклидова метрика vs взвешенные метрики | KNN с адаптивными весами признаков, поиск ближайших соседей в эмбеддингах, feature scaling |
